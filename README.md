# 🐍 Python — Técnico em Desenvolvimento de Sistemas

Ambiente pronto do **VS Code no navegador** (GitHub Codespaces) para as aulas do Prof. Felipe.

## Como usar
1. Entre com sua conta do GitHub.
2. Clique em **Code → Codespaces → Create codespace on main**, ou use o botão do site da turma.
3. Espere abrir (na primeira vez demora 1–2 minutos).
4. Abra um arquivo `.py` e clique em ▶ (canto superior direito) para rodar. O resultado aparece no **Terminal**, embaixo.

## Pastas
- `exemplos/` — programas de exemplo das aulas
- `projetos/` — crie aqui os seus projetos

## Dicas
- Terminal: `python exemplos/01_ola_mundo.py`
- Servidor Flask: `python exemplos/05_api_flask.py` e abra a porta **5000** na aba *Portas*.
- Para salvar no GitHub: aba **Controle do código-fonte** → escreva a mensagem → **Commit** → **Sync**.
- ⚠️ O plano gratuito tem cerca de **60 horas por mês**. Feche o Codespace quando terminar: menu ☰ → **Codespaces: Stop Current Codespace**.
